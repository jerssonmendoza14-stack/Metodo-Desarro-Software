# Comandos

## 1. Crear una rama local con mi nombre

- Ejecuto `git branch` para verificar la rama actual.
- Ejecuto `git branch jmgiraldo` para crear mi rama.
- Ejecuto `git branch` para verificar que la rama fue creada.
- Ejecuto `git checkout jmgiraldo` para cambiarme a mi nueva rama.
- Ejecuto `git branch` para verificar que estoy trabajando en `jmgiraldo`.

## 2. Crear un nuevo commit en dicha rama local

- Creo o modifico un archivo.
- Ejecuto `git status` para verificar los cambios.
- Ejecuto `git add .` para agregar los cambios.
- Ejecuto `git commit -m "Agrego mi archivo personal"` para crear el commit.
- Ejecuto `git log` para verificar el commit realizado.

## 3. Subir mi rama local al repositorio remoto

- Ejecuto `git push origin jmgiraldo` para subir mi rama al repositorio remoto
